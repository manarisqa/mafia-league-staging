### Что изменилось

- **Пульт.** Круглый стол с десятью или девятью местами, более плотный
  двухколоночный вид для iPad portrait, крупные цели на телефоне и
  доступный на телефоне таймер текущей речи. Речи, защиты, последнее
  слово и ночные проверки используют таймеры. Счёт предыдущей стадии
  голосования больше не переносится в переголосование. Добавлены
  исправления роли и никнейма с причиной, независимые выстрелы и запись
  неопределённого итога. Undo/redo, локальный архив, скрытие экрана и
  JSON с SHA-256 сохранены.
- **Протокол и результат.** Облачное хранилище закрыто для гостей,
  игроков и других администраторов. При сохранении проверяются
  контрольная сумма, ревизия и продолжение исходного журнала. Утверждение
  выполняется через существующий черновик партии League Core. Привязка
  ведущего и мест идёт по UUID. Сервер воспроизводит закрытый протокол,
  PostgreSQL проверяет опубликованную проекцию, а результат и квитанция
  фиксируются одной транзакцией.
- **История и Skill.** Утверждённый результат попадает в единый снимок
  истории, профилей и рейтинга. Состав, история и UUID исторических
  игроков сохраняются. Правила допуска и оригинальная `team-logit-v1`
  сохранены побайтно. Short9 влияет на историю и статистику.
- **Языки и никнеймы.** Добавлены RU/UK для главной, вечеров, RSVP,
  истории, протоколов, профилей, рейтинга и административных разделов,
  включая пульт. Для старых профилей с никнеймом он используется
  в публичном снимке, для остальных доступно ранее сохранённое имя.
- **Инфраструктура.** Изменения подготовлены двумя добавочными миграциями.
  Production v1.2.1, основная Supabase и `main` не изменялись. Турнирное
  оценивание и AI Judge остались вне спринта.

Браузерные проверки шли через локальные GoTrue, PostgREST и PostgreSQL
с синтетическими данными. Подтверждение почты в локальном Auth было
автоматическим. Проверки заполненной базы и запись тестов выполнялись
только в изолированном локальном контуре.

### Preview и оставшиеся ограничения

- [Vercel Preview ветки PR №18](https://mafia-league-owner-preview-git-feat-referee-ci-718107-manarisqa.vercel.app)
  использует существующий проект `mafia-league-owner-preview`. Доступ требует
  сессии Vercel владельца. Текущий статус сборки смотрите в [PR №18](https://github.com/manarisqa/mafia-league-staging/pull/18).
- Сетевой прокси Codex Cloud возвращал 403 для Vercel Preview и
  `geinamuvqejjxsnijxol.supabase.co`. Конфигурация среды отклонила запрос на
  расширение доступа. Доступа на запись к тестовой Supabase в текущей
  сессии не было. Добавочные миграции на удалённой базе ещё не подтверждены.
  Существующий тестовый seed и начальные миграции там не запускались.
  [Порядок проверки схемы](../supabase/README.md)
- Удалённый E2E под ролями, подтверждение почты на удалённом Auth, физический
  iPad/iPhone с Safari, сон и поворот устройства остаются непроверенными.
  Таймер работает в текущей вкладке. Перезагрузка восстанавливает протокол,
  таймер нужно установить снова.
- Синхронизация явная. Конфликт требует выбора версии с возможностью
  экспорта своей копии. Повторное утверждение защищено по ID протокола и
  ID партии. Две независимо созданные записи одной физической игры в
  разных черновиках оператор должен выявить при сверке.
- Игрок с UUID, который был удалён или заменён после составления протокола,
  не будет автоматически сопоставлен по имени. До начала партии можно
  выбрать актуальный профиль; для завершённого протокола требуется
  сверка реестра и исправление истории назначения.
- Материалы `/learn`, редактор профиля самого игрока, расширенная аналитика,
  очередь и уведомления остаются пунктами постоянного плана. Глубокий журнал
  действий сохраняется приватным, открытая карточка показывает официальный итог.
