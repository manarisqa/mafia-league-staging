## Проверки

- `npm ci`, `npm run lint`, `npm run typecheck`, `npm test` (67/67), `npm run build` и `git diff --check`.
- Браузерные сценарии запущены на production-сборке Next и синтетических PostgreSQL 16, GoTrue и PostgREST. Гость в обоих форматах прошёл от подготовки до отправки. Отдельный администратор обработал уточнение и исправление, утвердил результат, открыл уникальную карточку партии и сверил квитанцию. Из обоих форматов можно перейти к следующей партии. Short9 отображается в истории с исключением из основного League Skill.
- Проверены права гостя и обычного игрока, отказ с чужим кодом, повтор отправки, конфликт вкладок, восстановление в отдельном браузерном контексте, JSON с SHA-256, открытие исторического JSON, офлайн-перезагрузка очереди, регистрация с кириллицей, RSVP, профиль и рейтинг. Локальное применение существующей добавочной миграции сохранило все 25 исходных синтетических партий.
- Геометрия проверена в Chromium при 375×812, 390×844, 768×1024, 820×1180, 1180×820 и 1440×1000. Интерактивные места ≥44×44 CSS px, без пересечений с соседними местами и подписью ведущего. Горизонтального переполнения нет. Контраст предупреждения 9,74:1 и основной кнопки 6,22:1. Длинный ник сокращается визуально и доступен полностью в дереве доступности, в том числе по номеру места.
- На baseline проверка приёмки останавливается после первого обычного фола, так как в DOM отсутствует подсказка ведущему. Парные снимки дополнительно фиксируют исходные состояния таймера, дневного стола, закрытой проверки и пустого каталога.
- Браузерный прогон воспроизводится из `tests/browser/referee.mjs` на изолированной синтетической базе. Используйте `QA_APP_URL=http://127.0.0.1:55426 npm run test:browser` для интегрированного сценария. `QA_ACCEPTANCE_ONLY=1` включает регрессии приёмки, `QA_EDGE_ONLY=1` — таймер, отмену, восстановление и клубный сценарий. `QA_CAPTURE_BASELINE=1` снимает парные исходные состояния с работающего baseline. `QA_SCREENSHOTS` задаёт каталог снимков.
