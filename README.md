# Mafia League

Сайт клуба спортивной Мафии в Граце. Next.js App Router, TypeScript, Tailwind,
Supabase и Vercel. Владелец ведёт дальнейшую разработку с Codex. Постоянный
продуктовый план находится в [MASTER ROADMAP №15](https://github.com/manarisqa/mafia-league-staging/issues/15).

## Текущая линия разработки

Пульт и интеграция находятся в [PR №18](https://github.com/manarisqa/mafia-league-staging/pull/18)
поверх [PR №14](https://github.com/manarisqa/mafia-league-staging/pull/14), где
восстановлены League Core и оригинальная формула `team-logit-v1`. Ветки
сравниваются с актуальными heads этих PR. Владелец сам принимает решение о слиянии.
Результаты приёмки и текущие ограничения описаны в [отчёте спринта](docs/INTEGRATED_SPRINT_REPORT.md).

Для тестовой публикации используется проект Vercel `mafia-league-owner-preview`
и заполненная Supabase `mafia-league-preview` (`geinamuvqejjxsnijxol`).
Версии приложения и схемы для Preview должны совпадать. Порядок проверки
и список добавочных миграций приведены в [инструкции Supabase](supabase/README.md).

## Локальная разработка и проверка

Используйте Node 24 (минимум 22.13.0). Скопируйте `.env.example` в `.env.local`
и задайте публичные параметры локальной или тестовой Supabase. Без них
доступна демонстрационная витрина.

```sh
npm ci
npm run dev
npm run lint
npm run typecheck
npm test
npm run build
```

`npm test` запускается на локальном PostgreSQL/PGlite с синтетическими данными.
Smoke-проверки с настоящими Auth и REST проводятся на локальном стеке или в
защищённой Vercel Preview, подключённой к тестовой базе.

## Пользовательские сценарии

- Регистрация принимает игровой никнейм длиной 1–40 символов. Профиль, история,
  рейтинг и RSVP показывают никнейм, а для прежних профилей без ника используют
  сохранённое имя. ID игроков и их история остаются прежними.
- Язык RU/UK хранится в cookie. Даты игровых вечеров отображаются по времени
  Граца. Оригинальный League Skill учитывает подходящие Classic10, а Short9,
  ничьи, технические результаты и партии с удалениями остаются в статистике.
- Раздел «Ведущий» в админке открывает пульт Classic10/Short9. Сохранение на
  устройстве происходит автоматически. Облачная копия сохраняется вручную,
  проверяется контрольной суммой и доступна её автору. Утверждение связывает
  закрытый протокол с черновиком партии в League Core.
  [Работа с пультом](docs/REFEREE_WORKBENCH.md)
